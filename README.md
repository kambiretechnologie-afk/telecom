# S_NEX SARL - Site vitrine

Site web statique pour la société S_NEX SARL, conçu en HTML/CSS/JS avec Tailwind CDN.

## Structure

- `snex_website/index.html` : page principale
- `snex_website/assets/images/` : visuels du site

## Prévisualisation locale

```bash
cd snex_website
python -m http.server 8000
```

Puis ouvrez : http://localhost:8000/

## Publication en ligne

### GitHub Pages
1. Pousser ce dossier sur un dépôt GitHub.
2. Dans les paramètres du dépôt, ouvrir la section "Pages".
3. Sélectionner la branche principale et le dossier racine.
4. Publier.

### Netlify
1. Importer le dépôt GitHub.
2. Définir le dossier racine : `snex_website`.
3. Publier.

## Personnalisation

- Modifier les textes dans `snex_website/index.html`.
- Remplacer les images dans `snex_website/assets/images/`.
- Adapter les coordonnées e-mail / WhatsApp / téléphone si nécessaire.
